This is a complete static research group website template designed for GitHub Pages.

```text

assets/js/main.js
assets/img/*.svg
GUIDE_CN.md
CUSTOMIZE.md
.nojekyll
CNAME.example
```

## How to publish

1. Create a GitHub repository.
2. Upload all files in this folder to the root of the repository.
3. Go to repository `Settings` → `Pages`.
4. Choose `Deploy from a branch`.
5. Select `main` branch and `/root`.
6. Save and wait for GitHub Pages to deploy.

See `GUIDE_CN.md` for detailed Chinese instructions.
